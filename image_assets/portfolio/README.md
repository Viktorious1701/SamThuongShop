# portfolio/

Put the **bird photographs** here.

- Size: **long side 2000–2400 px** each
- Keep each photo's **natural shape** (do not crop to uniform)
- Format: JPEG, sRGB, ~1 MB each
- A curated **~12–24** to launch, grouped into a few themes

**For every photo, fill a row in ../photo-metadata-template.csv** (species EN+VN, location, date) — the site captions each image.

See ../ASSET-GUIDE.md item 3.
